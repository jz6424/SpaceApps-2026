Default style: NASA Space Apps brand guide.
Colors: blues lead. Deep Blue #07173F (main background), Electric Blue #0042A6, Neon Blue #0960E1, Blue Yonder #2E96F5, White #FFFFFF. Reds for energy: Rocket Red #E43700, Martian Red #8E1100. Accent: Neon Yellow #EAFE07, only for links, buttons, highlights; never backgrounds or headlines. Use the 60-30-10 rule.
Gradient: 45° linear, Electric Blue (top-left) to Deep Blue (bottom-right), gentle fade.
Type (Google Fonts): headings Fira Sans Black/Bold, H1 all caps with 5% letter spacing; body Overpass Regular/Light, Bold, Italic at 150% line height; code Fira Code. Fallbacks: system-ui, sans-serif; monospace.
Body text only on Deep Blue, Electric Blue or White. No Rocket Red backgrounds.
Accessibility: contrast at least 4.5:1 (WCAG AA); never use color alone to carry meaning.
Images: full color, unedited, inside rectangle or circle frames; never put text over images. Patterns (orbits, waves, grids) at about 25% opacity on blue.
Icons: thin line style with even strokes (Phosphor or Feather), sizes 16/24/32/64; add text labels when meaning is unclear.
Logo: Space Apps logo only, never NASA's official insignia; don't rotate, recolor, stretch, rearrange, or place on busy backgrounds.
Tone (not in guide, project default): clear, upbeat, kid-friendly.
